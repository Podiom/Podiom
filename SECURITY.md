# Security Policy

## Reporting a vulnerability

Please do not open a public issue for vulnerabilities, token exposure, private
workspace leakage, or sensitive transcript/log disclosure.

Use GitHub private vulnerability reporting for this repository:
https://github.com/Podiom/Podiom/security/advisories/new

Include the affected version or commit, impact, reproduction steps, and any
suggested fix. A maintainer will acknowledge the report, investigate privately,
and coordinate disclosure once a fix or mitigation is available.

## Supported versions

Security fixes target the current `master` branch and the latest published
release.
